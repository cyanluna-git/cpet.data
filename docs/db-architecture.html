🔗 DB 간 연결 포인트

platform DB ←→ analysis DB 연결 방식
submissions.workspace_path → data/workspaces/<uuid>/analysis.db 파일 경로로 연결. 서버가 파이프라인 실행 시 경로 전달.
report_catalog.html_content ← generate_report(analysis.db) 파이프라인 완료 후 api.py가 HTML을 platform DB에 저장.
subject_metric_snapshots.* ← analysis_results.value 핵심 지표 materialize. 크로스 피험자 쿼리 가속.
