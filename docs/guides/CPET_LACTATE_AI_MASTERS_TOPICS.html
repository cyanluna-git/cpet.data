Research Note

CPET + Lactate + AI 석사 논문 주제 후보

지금 쌓이고 있는 CPET, 호흡가스, lactate, 반복 측정 데이터를 바탕으로 실제로 수행 가능한 석사 논문 주제 5개를 한 장에서 비교한 노트입니다. 목표는 “재밌어 보이는 주제”가 아니라 “데이터로 끝까지 밀 수 있는 주제”를 고르는 것입니다.

Quick Take

가장 안정적인 주제는 1번, 현재 데이터와 제품 구조를 가장 잘 활용하는 주제는 2번, 가장 AI스럽고 매력적이지만 리스크가 큰 주제는 4번, 개인화 전략으로 확장하기 좋은 후보는 5번 군집화입니다.

  • 교수님 설득용으로는 1번이 가장 무난합니다.
  • 제품/리포트 기능으로 이어가려면 2번이 가장 강합니다.
  • 반복 제출 데이터가 계속 쌓이면 3번의 가치가 커집니다.
  • 4번은 “젖산 완전 대체”가 아니라 “surrogate feasibility study”로 좁혀야 안전합니다.
  • 5번은 군집 생성보다 군집의 의미와 안정성 검증이 중요합니다.
Decision Frame
  • 석사 논문 안정성: 1번 > 2번 > 3번 > 5번 > 4번
  • 지금 시스템과의 연결성: 2번 > 3번 > 5번 > 1번 > 4번
  • AI 느낌: 4번 > 5번 > 2번 > 3번 > 1번
  • 데이터 부족 리스크: 4번이 가장 큼
Topics

다섯 가지 후보를 한 번에 비교

아래 다섯 주제는 모두 현재 ZeLIA 데이터 자산으로 연결 가능하지만, 필요한 데이터 밀도와 논문 방어 난이도가 다릅니다.

1

LT1/LT2 통합 추정 비교

호흡가스 기반 threshold와 lactate 기반 threshold가 얼마나 일치하는지 비교하고, 개인별 차이가 왜 발생하는지 설명하는 연구.

  • 연구문제: 두 방식은 언제 일치하고 언제 어긋나는가?
  • 가설: 집단 평균은 비슷하지만 개인 수준 차이는 분명하다.
  • 필요 데이터: VO2/VCO2/VE/HR/Power + stage lactate + 프로토콜 메타
  • 분석방법: Bland-Altman, ICC, mixed-effect model, 통합 threshold 추정 비교
  • 예상 한계: 채혈 포인트 부족, 프로토콜 차이, 통합 모델 과적합 가능성
2

대사 유연성 지표 개발

FatMax, crossover, LT1, LT2, RQ 1.0 이전 연료 기여율을 합쳐서 개인의 metabolic flexibility를 설명하는 composite index를 만드는 연구.

  • 연구문제: 단일 지표보다 composite index가 상태를 더 잘 설명하는가?
  • 가설: 지방 활용과 threshold 구조를 같이 쓰면 더 풍부한 설명이 가능하다.
  • 필요 데이터: substrate, FatMax, crossover, LT1/LT2, body composition, 반복 측정
  • 분석방법: 상관구조 분석, PCA/factor analysis, weighted score 후보 비교
  • 예상 한계: gold standard 부재, score weighting 타당성 설명 필요
3

반복 측정 longitudinal 분석

같은 사람이 여러 번 CPET를 했을 때 어떤 지표가 먼저 변하고, 어떤 지표가 늦게 따라오는지 보는 시간축 연구.

  • 연구문제: 개선은 VO2max보다 submaximal 지표에서 먼저 나타나는가?
  • 가설: LT1/FatMax가 초기 적응을 더 먼저 포착한다.
  • 필요 데이터: subject x time 반복 CPET, lactate curve, body composition
  • 분석방법: snapshot table, delta/slope, growth model, responder subtype 분류
  • 예상 한계: 반복 측정 수 부족, 측정 간격 불규칙성
4

lactate surrogate model

호흡가스, 심박, 파워만으로 혈중 젖산 반응을 얼마나 추정할 수 있는지 보는 가장 AI다운 주제.

  • 연구문제: 채혈 없이 lactate curve 또는 threshold zone을 어느 정도 복원할 수 있는가?
  • 가설: 절대 수치보다 threshold-aware 분류가 더 안정적이다.
  • 필요 데이터: stage lactate + 동기화된 VO2/VCO2/VE/RER/HR/Power + protocol metadata
  • 분석방법: ridge/XGBoost/sequence baseline 비교, subject-wise CV, calibration 실험
  • 예상 한계: 과적합 위험, 데이터 수 부족, “대체 가능성” 해석 과장 위험
5

phenotype clustering

CPET, substrate, threshold, lactate feature를 이용해 피험자를 몇 가지 대사 phenotype으로 나누고, 그 의미를 해석하는 연구.

  • 연구문제: 재현 가능한 phenotype cluster가 실제로 형성되는가?
  • 가설: 군집은 단순 VO2max 고저가 아니라 연료 사용과 threshold 구조 조합으로 나뉜다.
  • 필요 데이터: feature set, lactate curve feature, body composition, 가능하면 반복 측정
  • 분석방법: scaling, 결측 처리, clustering 비교, stability analysis, cluster 해석
  • 예상 한계: 군집이 예쁘게 나와도 생리적 의미가 약하면 가치가 떨어짐
AI Role

각 주제에서 AI가 실제로 기여하는 부분

1. LT1/LT2 통합 추정 비교

  • 통합 threshold estimator 구축
  • feature selection으로 불일치 원인 설명
  • 개인차와 집단 경향 분리 모델링

2. 대사 유연성 지표 개발

  • PCA, factor analysis, regularized regression 기반 가중치 설계
  • 반복 측정 데이터가 쌓일수록 score update rule 보정
  • explainability로 점수 구성 근거 제시

3. 반복 측정 longitudinal 분석

  • time-series feature engineering
  • change velocity, momentum, delayed response 같은 파생변수 생성
  • future response prediction 실험 가능

4. lactate surrogate model

  • 회귀, tree-based, sequence model 비교
  • subject-specific calibration
  • uncertainty estimation과 SHAP 해석

5. phenotype clustering

  • 비지도학습과 차원축소가 핵심
  • cluster stability analysis가 중요
  • 해석 가능한 cluster labeling이 AI 기여를 명확하게 만듦
Comparison

어떤 주제를 고르면 좋은가

주제 강점 약점 추천도
LT1/LT2 통합 추정 비교 해석이 쉽고 논문 구조가 안정적 새로움이 상대적으로 약할 수 있음 매우 높음
대사 유연성 지표 개발 현재 데이터와 제품 구조에 가장 잘 맞음 지표 정의의 타당성을 잘 설명해야 함 매우 높음
반복 측정 longitudinal 분석 snapshot/feature 구조 활용성이 큼 반복 데이터 밀도에 성패가 좌우됨 높음
lactate surrogate model 가장 AI스럽고 흥미롭다 과적합과 해석 과장 리스크가 큼 중간~높음
phenotype clustering 개인화 전략으로 확장 가능 군집 안정성과 해석 타당성 확보가 어려움 중간~높음

개인적으로 4번이 끌린다면, 제목은 “젖산 완전 대체 모델”보다 “surrogate feasibility study”로 줄이는 편이 훨씬 안전합니다.

Recommendation

가장 현실적인 전략

옵션 A: 2번을 메인, 4번을 부가 실험

가장 추천하는 구조입니다. 메인 논문은 대사 유연성 지표 개발로 안정적으로 끌고 가고, lactate surrogate는 exploratory analysis로 붙입니다.

  • 논문 방어가 상대적으로 쉽습니다.
  • 지금 시스템과 제품 기능으로 바로 이어집니다.
  • AI 실험도 넣되 과장하지 않을 수 있습니다.

옵션 B: 4번 단독, 다만 범위를 줄이기

정말 AI 모델링을 메인으로 하고 싶다면, “lactate replacement”가 아니라 “threshold-aware surrogate feasibility”로 범위를 좁혀야 합니다.

  • 목표를 완전 대체가 아니라 가능성 평가로 둡니다.
  • subject-wise cross validation을 강하게 걸어야 합니다.
  • 해석 가능성과 한계 분석을 같이 써야 합니다.

옵션 C: 5번 군집화를 메인으로 하기

군집화 자체보다는, 각 cluster가 어떤 생리적 의미를 갖는지와 이후 변화 패턴과의 연결을 설명하는 방향으로 가야 합니다.

  • 지금 만든 snapshot/feature 구조와 잘 맞습니다.
  • 개인화 리포트나 phenotype labeling으로 확장하기 좋습니다.
  • 군집 수를 예쁘게 만드는 것보다 해석 가능성이 더 중요합니다.
