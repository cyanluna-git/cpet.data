Paper Review Brief

이 논문은 새로운 생리학보다 기존 과학을 잘 포장한 구현 전략에 가깝다

VO2/VCO2에서 기질 산화를 구하고, RER = 1.0 이전까지 지방·탄수화물 기여를 적분하고, FatMax, crossover, optional lactate coupling을 묶어 하나의 metabolic flexibility metric으로 제시하는 접근은 제품 기능으로는 가치가 있지만, 생리학적 신규성이나 broad patent claim으로는 방어가 약합니다.

  • 가장 가까운 prior art는 2025 graded-exercise intervention study입니다.
  • 방어 가능한 차별점은 개념보다 breath-by-breath 처리, crossing interpolation, artifact handling, validation입니다.
  • ZeLIA는 당분간 RQ 1.0 fuel contribution과 해석형 리포트 기능을 중심으로 가는 편이 안전합니다.
Internal Position

현재 코드베이스의 연료 기여율, FatMax, crossover 해석은 계속 가져가도 됩니다. 다만 Metabolic Flexibility Index 같은 단일 점수는 연구용 레이어로 낮추고, raw observables와 composite score를 분리해 설명해야 합니다.

Metric Definition

논문이 실제로 정의하는 것

최종 점수 공식을 명시하기보다, 어떤 입력과 어떤 처리 파이프라인을 묶어 metabolic flexibility라고 부르는지가 핵심입니다.

Core pipeline

논문이 사실상 제안하는 것은 아래 처리 흐름입니다.

VO2, VCO2, time, workload, optional HR, optional lactate
↓
RER = VCO2 / VO2
↓
fat / CHO oxidation + kcal conversion
↓
RER 1.0 crossing interpolation
↓
integration to boundary + FatMax + crossover + optional lactate features

즉 novelty가 생긴다면 점수 이름보다 exact crossing 처리와 noisy breath data handling 쪽이 더 중요합니다.

Not actually new

  • VO2/VCO2 기반 substrate oxidation
  • RER ≤ 1.0 실무 cut-off
  • FatMax, MFO, crossover 해석
  • lactate와 substrate oxidation을 함께 읽는 접근
  • 논문이 새롭게 포장하는 것은 physiology 그 자체보다, 여러 established observable을 하나의 operational metric으로 묶는 방식입니다.
  • 따라서 ZeLIA의 현재 기능을 제품 feature로 유지하는 것은 타당하지만, 강한 proprietary claim은 피해야 합니다.

Closest pressure point

  • RER = 1.00까지 fat/CHO oxidation 계산
  • RER < 1.00 구간의 total energy 계산
  • fat, CHO, lactate AUC 계산

What may still differ

차별화가 있다면 concept가 아니라 implementation detail입니다.

  • breath-by-breath interpolation
  • partial-interval integration
  • artifact rejection
  • lactate-informed correction

Guardrails

내부 운영 원칙

논문을 읽고 난 뒤 최소한 이 원칙들은 고정해두는 편이 좋습니다.

Terminology

RQ와 mouth-level RER를 혼용하지 않습니다. 구현은 사실상 RER = VCO2 / VO2입니다.

Boundary honesty

RER = 1.0는 practical cutoff이지 절대적인 physiological truth가 아니라는 점을 설명합니다.

Protocol safety

no crossing, missing lactate, protocol mismatch, noisy breath data는 리포트에서 분명히 경고합니다.

  • single score는 반드시 versioned experimental layer로 둡니다.
  • raw observables와 composite interpretation을 같은 위상으로 놓지 않습니다.
